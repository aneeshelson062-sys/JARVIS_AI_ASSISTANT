# JARVIS – Personal AI Assistant

JARVIS is a personal AI assistant developed using Python.

The project aims to build a modular, extensible assistant that supports
conversational AI, voice interaction, persistent memory, task management,
and basic computer automation.

## Project Goals

- AI-powered chatbot
- Voice recognition and speech output
- Persistent memory
- Task and reminder management
- Basic computer automation
- File management

## Technology Stack

- Python 3.12+
- SQLite
- Git and GitHub

## Project Structure

The project follows a src-based package structure to separate application
code from configuration, tests, and other resources.

## Development Status

Currently in the initial architecture and environment setup phase.
